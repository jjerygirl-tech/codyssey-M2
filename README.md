\# 파이썬 기초 퀴즈 게임



\## 프로젝트 개요



Python 기본 문법을 연습하기 위해 만든 콘솔 퀴즈 게임입니다.

메뉴에서 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록 확인, 최고 점수 확인을 할 수 있습니다.



\## 퀴즈 주제와 선정 이유



퀴즈 주제는 파이썬 기초입니다.

이 과제에서 Python을 배우고 있으므로, 학습한 함수와 자료형, 조건문 등의 내용을

문제로 다시 확인하기 위해 이 주제를 선택했습니다.



\## 개발 환경



\- Python 3.10 이상

\- Windows PowerShell

\- 외부 라이브러리 없이 Python 표준 기능 사용
